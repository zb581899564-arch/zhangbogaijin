# P6.1.1 评价后PDDR环境选择校正报告

日期：2026-08-09  
语义：`fatigue_improved`生产派生线上的`B2P=B2+EVALUATED_PDDR`  
状态：`completed`

## 结论

作者生产母线中的PDDR调用已增加显式双模式。默认`AUTHOR_PDDR_ACTIVE`不改变P6.1及更早行为；校正模式`EVALUATED_PDDR`只在全局后代完成P5疲劳评价和Qg奖励结算后运行，并把选中解及其对应作者个人历史真正写回主种群。

## 固定时序

```text
保存已评价父代及历史
→ Qg选择领导
→ CFVF生成全局后代
→ 每个后代完整评价一次
→ 局部搜索和历史更新前结算Qg奖励
→ 合并后代在前、父代在后的已评价候选
→ 作者语义PDDR-FF稳定选择
→ 真正替换主种群和作者历史
→ 更新作者个人历史及全局非支配集合
```

候选通过不可变记录携带来源、父槽位、评价序号和历史快照。父代不重新评价，PDDR评分和比较不计FE。

## 验证

- 组件测试覆盖未评价候选拒绝、候选—历史映射、后代优先的稳定同分顺序和作者PDDR评分；
- `20_2_3_1`使用100粒子、2000 FE，初始100次评价后产生1900个CFVF后代，PDDR共执行19代、选择1900个存活槽位；
- 每个后代严格1 FE，父代、PDDR和历史复制为0 FE；
- 旧`AUTHOR_PDDR_ACTIVE`工厂仍保持默认，旧P6.1配置文本和行为不变；
- Java 8字节码、六模块打包及P2–P6.2定向回归通过；完整旧回归只有P1登记的3个构造器错误。
