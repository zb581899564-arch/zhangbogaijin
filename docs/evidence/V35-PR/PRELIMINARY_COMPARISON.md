## 4. 初步结论（单 seed，如实）

1. **Cmax 与 TEC 两个目标上 FULL 明确更好**（极值 −4.4% / −2.6%），TWC 极值略回吐
   （+0.6%）——三目标里两个领先、一个基本持平略差；
2. **前沿高度交错**：FULL 支配掉基线 80 个点，但 FULL 自身有 153 个点被基线支配
   （FULL 前沿更大、含更多被基线覆盖的区域点）；联合前沿 463 点中 FULL 贡献 254、
   基线贡献 209——**FULL 覆盖面更广，但"全面支配基线"不成立**；
3. 前沿规模 407 vs 289 不直接等于质量（PDDR 保留规则 + 三目标 rank-0 膨胀，之前已解释）；
   真正的质量结论要等 **V35-P26** 的统一 reference + HV/IGD+；
4. 单 seed 单实例，样本量 1——方向性信号可信（Cmax/TEC 领先方向与 20k/100k 诊断一致），
   **不升级为统计或论文结论**。

**三实例方向汇总（每实例单 seed，样本量仍为 1/实例）**：
- **Cmax：3/3 实例我方领先**（−4.4% / −1.0% / −2.0%）；
- **TEC：3/3 实例我方领先**（−2.6% / −1.9% / −3.0%）；
- **TWC：2/3 领先**（−1.0% / −3.0%），20_2_3_1 上略回吐（+0.6%）；
- 前沿在三实例上均高度交错、互有支配，我方在联合前沿的贡献点数均更多（254/209、170/164、200/154）。

**判断**：Cmax/TEC 领先方向稳定；TWC 大体领先、个别实例持平略差；仍属单 seed 诊断，
多 seed 与统计显著性留待 V35-P25/P26。

## 7. HV/IGD/覆盖（离线计算，P8MetricCalculator 口径：池化参考归一化 + 1.1 参考点）

每实例以两前沿并集为经验参考；HV 值仅实例内可比。

| 实例 | HV 基线 | HV FULL | **HV 比值** | HV 并集 | FULL 份额 | 基线份额 | C(基线→FULL) | C(FULL→基线) | IGD 基线 | IGD FULL |

结论（单 seed，如实）：
- **HV 三实例全部我方胜出**（比值 1.024–1.045，+2.4%~+4.5%），且我方单臂即覆盖
  并集 HV 的 94%–99%（基线 92%–94%）；
- **IGD 三实例全部我方更优**（对池化参考更近）；
- C 覆盖双向交错（两臂各覆盖对方约 20%–38% 的点）——与"极值更好 + 区域交错"一致；
- HV 幅度属"温和领先"，不是碾压；多 seed 稳定性仍待 V35-P25/P26。
