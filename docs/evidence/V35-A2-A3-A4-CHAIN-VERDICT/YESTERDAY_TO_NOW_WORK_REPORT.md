## 先给结论

当前可以保留的是**完整 A4 链条作为待多实例确认的主候选**，不是“每一个中间模块都单独有效”。

```text
A2 (CFVF)
  → A3 (个人档案 + Qp + 双Q) ：单独看，稳定伤害前沿质量
  → A4 (A3 + CA-TA-Lite)    ：强力恢复，并在当前100-job先导中超过A2
```

所以此时绝不能：

- 宣称个人档案/Qp/双Q单独有效；
- 因为 A3 有害就直接删掉它；
- 再用小阈值、动作优先级或奖励权重反复碰运气；
- 修改 PDDR、DOE 配比或恢复 4500 正式矩阵。

唯一合理的下一阶段，是把 **A2 与 A4** 作为核心竞争者，先做受控的多实例确认；A3 仅作为
机制链中间臂，用于消融解释，不作为论文“独立正贡献”声明。

## 2. 为什么此前要做 D0--D3、Q0、Q1

Stage2 先导发现 A2→A3 是机制链唯一显著负增量。它包含三个同时变化的组件：

```text
个人档案
→ Qp 四动作与TD奖励
→ 10%预热与P5/G5双Q冻结
```

若不拆开，无法判断是档案、Qp、奖励、双Q，还是它们组合导致退化。因此进行的工作不是参数搜索，
而是把“整块 A3 有害”拆成可验证因果链。

### 2.1 D0--D3 四臂拆分（12条50k）

- D0：A2 精确控制；
- D1：D0 + 个人档案 + 固定方向 pbest；
- D2：D1 + 同步 Qp 四动作/未裁剪奖励；
- D3：D2 + 现有预热与 P5/G5 冻结。

结果：D0→D1 已退化；D1→D2 又退化；D2→D3 未满足稳定退化门。因此双Q冻结不是当前主因，
而个人档案方向领导与 Qp 块均存在风险。此时结论仍为
`COMPOSITE_BLOCK_UNRESOLVED`，因为 D1 和 D2 两段都出问题。

### 2.2 奖励裁剪检查（6条50k）

发现旧实现的方向奖励有公式一致性问题：`oldPhi≈0` 时可产生极端负数。裁剪实现使数值回到
`[-1, 1]`，但三 seed 先导性能没有改善，因此它保留为“公式纠错诊断能力”，不能反向作为性能修复。

### 2.3 Q0：把“动作策略”和“TD学习”拆开（3条50k）

Q0 与 D2 的个人档案和四动作 pbest 完全相同，但强制只观察：动作与档案正常发生，TD 奖励和
Q 表写入为零。

结果：D1→Q0 仍稳定退化；Q0→D2 不满足稳定退化门。因此当前能归因的是**未学习时的 Qp 动作
策略**，不是 TD 学习或双Q冻结本身。这一结论在
`docs/evidence/V35-A3-D2-QP-SETTLEMENT/` 中已经闭合。

### 2.4 Q1：零表并列优先 DIRECTIONAL（3条50k）

Q1 只修正零表贪心并列时“第一个合法动作 KEEP”的偏置；它真实将三 seed 的方向动作由
237/30000 增至 2104/30000，但没有达到预注册改善门，且仍稳定劣于 D1。

这条假设已被否定：它排除了一个看似直接、实际不充分的修复方向。详见
`docs/evidence/V35-A3-D3-QP-COLD-START-TIE/FINAL_ACCEPTANCE_REPORT.md`。

这两点意味着：当前问题不是“点多”或“PDDR一定错了”，不能靠改档案/PDDR 回避 A3 的因果问题。

## 5. 我建议的下一步：一次有判别力的整体门

不再做任何 Qp 微调。下一步只应预注册一次 **A2 vs A4 多实例确认门**：保持全部冻结条件，
使用新的、未用于当前裁决的实例与 seed，考察 A4 是否在不牺牲 HV/IGD 的条件下稳定超过 A2。

裁决逻辑必须预先写死：

```text
若 A2→A4 多实例仍满足质量门：
  保留 A4 作为完整耦合主候选；论文中只能表述“档案/Qp/双Q与CA-TA-Lite共同作用”，
```

在这条整体门之前，任何奖励裁剪、动作优先级、档案容量、PDDR或教师策略变化都只会污染因果链，
不应继续做。
