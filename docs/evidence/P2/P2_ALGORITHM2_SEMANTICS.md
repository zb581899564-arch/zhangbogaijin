## 正文补充的工人分配分支

- 当前阶段待分配工件数不多于工人数：随机选择工人。P3的`PUBLISHED_STOCHASTIC`必须注入并记录随机源。
- 工件数多于工人数：等待最先完成上一任务的工人。
- `DETERMINISTIC_CANONICAL`的稳定破平属于P3，不在P2预先实现。
- P2没有对Algorithm 2进行可执行化，评价预算为0。
