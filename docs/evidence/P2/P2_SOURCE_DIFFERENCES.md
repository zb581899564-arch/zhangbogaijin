## PDF文本层异常

学位论文PDF第59页的文本抽取层会额外返回`91382745106`等与可见Fig.4-2不一致的数字。150 DPI页面渲染清楚显示，可见四向量与ESWA Fig.3一致。因此P2遵循“视觉页面优先于布局不可靠的文本抽取”原则，不建立虚假的第二套论文编码。

## 当前Java证据边界

- `DefaultIntegerPermutationSolution`仍保留作者初始化、随机性、固定实例文件和复制行为。
- P2没有修复P1登记的通用jMetal构造器错误，也没有把新契约接入`EDHHFSPW.evaluate()`。
- 作者实际行为仅作为P3差异诊断输入，不能反向覆盖`published_baseline`。
