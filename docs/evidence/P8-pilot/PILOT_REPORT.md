# 张博改进小规模预实验报告

## 定位

本实验是P9之前的趋势预检，不是正式实验。为避免重复运行完全相同的配置，直接复用已经通过完整性审计的P8-v3小规模运行记录，并从中抽取完整递进链重新汇总。

## 设计

- 实例：第四章10工件桥接实例、`20_2_3_1`；
- 种子：`20260808/20260809/20260810`；
- 种群：100；
- 单次预算：最多2000 FE；
- 相同实例与seed使用相同初始四向量；
- 递进链：`B1→B2→B3→B4→B5→B6→B7→FULL`；
- `B0`仅作为无疲劳规范基线参考，不与B1–FULL直接作算法优劣结论；
- 指标：HV越大越好，IGD越小越好；同时观察三个目标和疲劳诊断；
- 样本仅3个seed，不执行显著性检验，不形成论文结论。

## 配对趋势

按两个实例、三个seed组成的6个配对观察：

| 增量 | HV改善 | IGD改善 | 说明 |
|---|---:|---:|---|
| B1→B2 | 5/6 | 3/6 | CFVF总体有信号，但IGD不稳定 |
| B2→B3 | 0/6 | 0/6 | 6/6完全相同，符合档案影子/记忆隔离预期 |
| B3→B4 | 2/6 | 3/6 | Q-pbest效果混合 |
| B4→B5 | 1/6 | 2/6 | 分块冻结在当前短预算下未显示稳定HV/IGD收益 |
| B5→B6 | 4/6 | 2/6 | 新邻域能改善部分目标，但综合收敛不稳定 |
| B6→B7 | **5/6** | **6/6** | CA-TA是本次最稳定的正向增量 |
| B7→FULL | 3/6 | 3/6 | FAT上下文效果依赖实例，当前不能判定稳定增益 |

## 初步判断

1. 三个创新点都能运行并产生可观察差异，不是空开关。
2. CFVF有初步改善信号；个人档案单独作为影子记忆时不改变结果，归因边界正常。
3. Q-pbest和分块冻结在2000 FE短预算下表现混合，需要更长预算和更多seed判断。
4. `B6→B7`最稳定，说明上下文Test-and-Apply比固定O1–O13更值得保留。
5. `B7→FULL`并非稳定提升：黄金实例改善，20工件实例HV/IGD略退但Cmax改善。FAT上下文需要在正式实验中重点做敏感性和消融。
6. 20工件实例的Fmax接近1，说明当前`r=0.30`场景压力较高；这不是代码错误，但正式实验应同时报告FE、恢复和阈值指标，不能只看三目标。

## 边界

- 本实验没有新增500000 FE运行；
- 没有参数调优；
- 没有Wilcoxon/Friedman/Holm检验；
- 工程参考前沿不是真实Pareto前沿；
- `sampled_reproduction_accepted=false`与`full_reproduction_accepted=false`保持不变。
