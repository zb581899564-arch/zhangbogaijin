# V35 ND0 Gate A 纯观察审计报告

## 结论

```text
archive_gate_a = BLOCKED
nd1_nd4_started = false
current_archive_semantics_unchanged = true
pddr_semantics_unchanged = true
```

本轮使用 `ND0_FULL_ARCHIVE_CONTROL`，没有裁剪档案、没有改变教师候选、没有修改 PDDR，也没有启动 ND1--ND4。四条短程运行全部完成且非法解、重复评价为0，但四条均未满足预注册硬门：

```text
exactDedup(decision-front) = exactDedup(observed-full-front)
```

这表明当前 `decision-front` 不是“所有已评价候选的完整发现前沿”。算法的决策档案只接收进入其既定生命周期的候选；`observed-full-front` 则被动观察每一次完整评价，因此会保存部分从未进入决策档案的非支配候选。该差异不是通过切换论文指标来源来修复的理由。

## 门槛解释

- “非支配点多由近重复污染造成”没有得到支持：三个20-job运行的0.1%近重复率为0--2.13%，远低于20%触发门。
- 运行耗时门没有触发：20-job档案更新与教师扫描合计约4.4%--4.9%，低于25%。
- 教师方向遗憾门触发：三个20-job中位数均大于5%，P95均大于20%。该信号允许把教师视图保留为后续候选，但本轮禁止自动运行ND1/ND2。
- 更强的 decision/observed 等价硬门在四条运行中全部失败，因此 Gate A 总体为 `BLOCKED`。在解释清楚“决策档案”和“完整发现前沿”的论文口径前，不得推广任何活动档案候选。

## 行为等价与证据

- 2,000 FE 的 ND0 ON/OFF 回归保持初群、完整评价轨迹、前沿、P6/PDDR/Qg/Qp/CA-TA事件流、Qg/Qp表和FE一致。
- Gate A 每条运行保存 `behavior-hashes.properties`、两类前沿、K25/K30/K50展示/敏感性集合、事件表与文件级SHA-256。
- 四个目录的文件清单已反向复算，错误数为0。

本报告不修改当前正式主指标：既有实验仍使用当时冻结的 `decision-front`；`observed-full-front` 只作为诊断证据，不能与主指标混用。
