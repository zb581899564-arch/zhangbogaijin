## 与其他纪录的对照

G1的Qg社会老师长期使用的并不是201.279，而是较早的Cmax=`205.902163389086`记录：

- 作为社会老师教过680个G1粒子；
- 覆盖34个外层代；
- 从FE 3473持续到FE 16828。

因为G1每代有20个粒子，`680=34×20`说明Qg在34个完整外层代中把205.902作为统一社会领导。另一个Cmax=`209.385590720839`的纪录仅作为社会老师出现1代，即20个粒子。

## 原因解释

Qg的社会领导选择不是“全局档案中Cmax最小者必选”：

1. 动作0保持上一轮领导；
2. 动作1使用本群历史领导；
3. 只有动作2才从全局非支配档案做二元锦标赛。

所以201.279虽然留在全局档案并有参选资格，但没有被Qg实际选中。它只经容量6谱系档案和Qp个人领导路径，被部分G1粒子使用15次。到FE 13224后，这条个人教学路径也停止了。

这解释了20k主审计中观察到的现象：历史最优仍在全局档案，但14k FE后当前G1的最好Cmax开始明显退化。当前问题不仅是候选生成停滞，还包括“全局Cmax极值没有稳定成为G1社会老师”。
