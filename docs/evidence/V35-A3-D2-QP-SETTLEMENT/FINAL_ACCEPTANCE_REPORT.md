# V35-A3-D2：Qp 动作策略与 TD 奖励学习最小拆分——最终验收

## 结论

本工作包的唯一预注册裁决是：

```text
a2_a3_d2_root_cause = QP_ACTION_POLICY_HARMFUL
```

这只回答 D1→D2 这一段：在已经有谱系个人档案的条件下，**将固定方向个人领导替换为尚未学习的
Qp 四动作选择**，已经造成稳定退化。它不证明 TD 奖励学习本身是当前主因，也不推翻更上游
`D0→D1` 的个人档案加固定方向领导退化结论。

## 严格对照

```text
D1 = 谱系个人档案 + 固定方向 pbest；无 Qp 动作
Q0 = D1 + Qp 四动作实际选择；Q 表永远不学习
D2 = Q0 + 原有 LEGACY_UNCLIPPED 奖励与 TD 更新
```

三臂固定为同一实例 `20_2_3_1`、相同三 seed、相同100粒子显式初群、FM3、无Shift、单族、
序列无关SUT、`[20,40,20,20]`、`GLOBAL_ORIGINAL` PDDR及 `CA-TA-Lite → inherited LS`。

稳定退化门为：至少2/3配对seed同时“HV下降且IGD变差”，且中位`ΔHV≤-2%`或中位

## 定位到的机制现象

Q0三个Q表均保持零表：`tableNonZeroCells=0`。控制器在贪心选择时，对并列Q值稳定保留第一个
合法动作；动作枚举中该位置是`KEEP`。因此，Q0在30,000次真实Qp选择中出现：

```text
KEEP          29,146  (97.15%)
DIRECTIONAL      237  (0.79%)
EPSILON          599  (2.00%)
COMPLEMENTARY     18  (0.06%)
```

这不是“档案失效”：Q0仍更新谱系档案、没有fallback、并真实使用被选pbest。问题也不能简化为
“TD奖励太大”：Q0没有任何奖励样本或TD transition，仍在D1→Q0跨2/3 seed退化；相反Q0→D2
没有达到同一稳定退化门。未裁剪奖励的数值极端风险仍保留为D-098已确认的**公式一致性问题**，
但本实验不允许把它冒充为完整性能因果。

## 对正式主线的影响

无即时影响。冻结正式Jar、A0--A4、`GLOBAL_ORIGINAL` PDDR、无界档案、DOE1
`[20,40,20,20]`以及暂停的4500矩阵均没有被修改或重启。

若后续要修复，只允许另行批准一个新的最小单变量臂：保持D1其余语义和同一初群不变，只改变
**Qp冷启动的动作选择/并列策略**。它必须先有预登记、2k重放门与50k三seed诊断；不得借机修改
奖励裁剪、个人档案容量、双Q时序、PDDR或DOE参数。
