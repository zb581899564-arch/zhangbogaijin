# P6.4 来源与语义边界

- 总体v2要求10%预热及`B=5`的P/G分块冻结，优先于P6.3细节中的同步Qg/Qp学习；同步行为保留为独立消融，不被覆盖。
- 用户确认冻结只约束Q值更新；冻结控制器仍观察本代变化并刷新状态。因此实现禁止奖励累计和TD提交，但继续执行贪婪动作语义。
- 用户确认预热边界必须按完整代向上取整，初始种群评价计入10%预算；同一代内禁止混用策略。
- 冻结Qg选择到全局锦标赛动作时仍允许动作自身的可注入随机事件；“贪婪冻结”不等于取消动作内部随机语义。
- P6.4仅降低两个控制器同步变化造成的非平稳性，不能宣称完全因果隔离。
- 路线图旧P6.4描述曾列出尚未实现的工厂间搜索和CA-TA-VNS；本次按批准计划校正为评价后PDDR及谱系继承闭环，P7机制继续后置。
