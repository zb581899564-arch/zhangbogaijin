# CA-TA真实时钟与确定性回放边界

## 现象

固定seed下使用真实`System.nanoTime()`重复FULL短程运行，接近的邻域平均代价可能因调度抖动发生次序变化，进而改变后续动作和前沿哈希。这不是随机源泄漏，而是总体v2把wall-clock纳入信用后产生的预期环境输入差异。

## 处理

- 正式烟测和性能测量：使用真实单调时钟，记录CPU/JVM环境，不承诺动作日志字节级一致。
- 算法语义、状态机、随机流和论文解释图回放：注入确定性审计时钟。
- B1/FULL各3次2000 FE审计回放已证明初始种群、FE、front、Qg/Qp表和机制摘要哈希一致。
- 真实时钟漂移的首次尝试保留在`04_dynamic-audit/replay-3x2000-attempt1-real-clock-drift`，不得删除或包装成通过。

## 结论

确定性审计时钟证明实现可回放；真实时钟运行证明实际代价信用被测量。两类证据用途不同，不得混写。
