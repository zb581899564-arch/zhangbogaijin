# P6.5 迁移前证据隔离说明

P6.5发现并修正了张博创新链路中`G2_CENTER/G3_TEC/G4_TWC`的职责错位。为保留研究审计链，历史证据不删除，但按以下规则使用：

- P2–P5.1中与子群无关的论文算例、编码、解码、SUT和疲劳公式证据继续有效。
- P6.0–P6.4及P7.1中迁移前的Q表、动作比例、子群方向统计、VNS方向结果和配置哈希统一标记为`legacy_pre_subgroup_migration`。
- 迁移前结果只能说明当时实现的工程行为，不再作为统一子群语义下的当前算法证据。
- P6.5之后的新Q表从零初始化，不转换旧Q值；旧VNS统计也不注入新CA-TA统计桶。
- 当前验收以P6.5重验日志、P7.2日志及对应SHA-256清单为准。

作者`MOHPSOQ`内部仍保留的裸组号属于冻结的`author_actual_legacy_inactive/compatibility`代码。P6.5不重写该巨型作者类的历史语义；张博活动创新路径必须通过集中语义类访问角色。
