## 解释边界

FULL的正式CA-TA代价信用包含真实wall-clock，故相同seed在不同重复中可能因操作系统调度和GC抖动选择不同的等价成本路径；例如100k FULL的局部FE为66800、67000、67000，前沿规模为430、478、478。这不是FE泄漏，但意味着论文正式实验必须固定CPU/JVM环境并采用独立重复，不能把真实时钟运行描述成字节级动作重放。

I1确定性时钟运行负责算法状态机和图形证据的严格重放；本报告负责真实运行成本。二者不可混写。
