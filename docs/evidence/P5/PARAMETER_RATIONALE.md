## 正式基准设置

| 参数 | 设置 | 实现口径 |
|---|---:|---|
| `λ_f,w,k` | `U(0.01,0.03)` | 每个实例按SHA-256键控采样一次并永久固定 |
| `μ_f,w,k` | `U(0.03,0.07)` | 每个实例按SHA-256键控采样一次并永久固定 |
| `r_k` | `0.30` | 最大疲劳工时增幅，公开配置参数 |
| `δ_f,w,k` | `r_k/(λ_f,w,k ln2)` | 派生字段，不独立配置或采样 |
| `Fwarn` | `0.80` | 疲劳诊断警戒阈值 |
| `Fsafe` | `0.90` | 首版仅记录超阈事件，不强制休息 |

采样键固定为：

```text
zhangbo-fatigue-v1
| 20260808
| instance SHA-256
| parameter type
| factory / worker / stage
```

由SHA-256前53位映射到`[0,1)`，因此遍历顺序、集合实现或调用次数不会改变既有参数。45个有效实例的参数文件已经物化到`java-jmetal58/fatigue-parameters/v1`，评价过程只读，不重新采样。

## 加工时间表达

论文和代码优先介绍直观的最大疲劳工时增幅`r`：

```text
AT = AT0 * [1 + r_k/ln(2) * ln(1 + F_start)]
```

当`F_start`趋近1时，倍率趋近`1+r_k`。生产母线中的`AT0`继续采用作者活动代码语义：

```text
AT0 = (ST + 0.1*ST) / (MS * WE)
```

论文`SUT/WE`口径继续由P3的`paper_verification_baseline`验证，不混入作者直接派生生产路径。

## 论文表述边界

论文应使用以下表述：

> 参数范围依据现有疲劳感知调度文献设定，用于构造具有个体差异的标准化实验场景。

不得表述为“真实工人的精确生理参数”。指数疲劳模型在本项目中是制造调度的计算抽象；如果后续获得真实工厂工人数据，再对`λ/μ/δ`进行数据拟合，那是独立的后续研究工作。

当前完成的是模型工程实现和方案语义对齐，不是人体生理参数实证，也不是论文级正式实验。
