# I0-v35 本人手算说明

这是一份按当前v3.5正式代码语义制作的空白手算题包，不是P8.6左移/右移题包。

固定语义：

```text
decoderMode=FM3
familyMode=DEGENERATE_SINGLE_FAMILY
setupMode=SEQUENCE_INDEPENDENT
shiftMode=NONE
pfSdstActive=false
seed=20260808
```

本人需要完成：

1. 将四向量按位置解码为工件、工厂、第一阶段机器和第一阶段工人；
2. 按工厂内JS顺序计算第一阶段；
3. 按上一阶段完工时间确定第二阶段顺序；
4. 第二阶段按代码规则选择机器，并比较全部合法工人的疲劳修正完成时间；
5. 逐工序计算开始时间、恢复、疲劳、基础/实际加工与设置时间、结束时间、能耗和成本；
6. 汇总Cmax、TEC和TWC，并填写疲劳诊断指标。

当前设置时间仍为序列无关：`SUT[job][stage]`。虽然加工顺序会改变工人疲劳，从而间接改变实际设置时间，但标准SUT不读取前序工件。

当前正式Decoder不执行FCLS/FCRS。旧I0-v2工作簿只保留为历史练习，不得将其中S1/S2结果抄入本表。

黄色单元格由本人填写；蓝色单元格是冻结输入或公式提示；绿色状态只能由本人填写后的自检公式产生。程序数值答案保持锁定，直到本人提交完成工作簿并冻结SHA-256。
