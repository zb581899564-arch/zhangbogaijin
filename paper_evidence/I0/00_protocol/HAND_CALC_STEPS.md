# I0本人手算步骤

本文件只说明方法，不包含任何I0计算结果。

## 1. 先完成四向量解释

对位置`p=1..5`逐项读取：

```text
JS[p] = 工件
FA[p] = 工厂
MA[p] = 第一阶段局部机器
WA[p] = 第一阶段局部工人
```

先按`JS`顺序把工件分到两个工厂，分别写出工厂内第一阶段顺序。

## 2. 先完成FM3基础调度S0

第一阶段按工厂内JS顺序调度；第二阶段按上一阶段完工时间执行ETC排序，同刻依次按上一阶段调度顺序和较小工件编号破平。

第一阶段直接读取MA/WA。第二阶段：第一个工件使用局部M1，其他工件选择最早可用机器；FM3枚举阶段合法工人并选择疲劳修正后完工时间最小者，同值取较小工厂全局工人编号。

每道工序先填写基础时长，再计算疲劳反馈：

```text
PT0 = ST / (MS * WE)
SET0 = SUT / WE
AT0 = PT0 + SET0
S = max(前序完工, 机器可用, 工人可用)
R = max(0, S - 工人上次结束时间)
Fstart = Flast * EXP(-mu * R)
multiplier = 1 + r / LN(2) * LN(1 + Fstart)
actualPT = PT0 * multiplier
actualSET = SET0 * multiplier
actualAT = actualPT + actualSET
C = S + actualAT
Fend = Fstart + (1 - Fstart) * (1 - EXP(-lambda * actualAT))
```

第一项任务前的等待不计为自然恢复；Cmax后的尾部时间也不计入自然恢复总时长。

完成一行后立即更新工件、机器、工人和疲劳状态。10道工序全部完成即得到`S0`。

## 3. 疲劳一致左移FCLS：S0到S1

按“阶段、开始时间、工件、工厂”的稳定顺序检查工序。对目标工序分别取得机器空档和工人空档，只有二者交集能够容纳疲劳修正后的动态工时才形成共同空档候选。

对候选执行：

```text
机器空档 ∩ 工人空档 → 得到共同空档
→ 同时把目标工序插入对应的更早机器序列槽位和工人序列槽位
→ 预测开始时间必须早于当前开始时间且预测结束不越过共同空档右端
→ 从DAG起点完整重算全部受影响工序
→ 重新计算恢复、疲劳、实际PT/SET/AT、结束时间和三个目标
→ 目标工序实际开始时间必须严格提前
→ 新Cmax不得变差
```

若候选被接受，立刻更新当前DAG和调度，再继续检查后续工序。全部检查完成后的调度记为`S1`。新版I0共有6个FCLS候选记录并有1个真实接受事件；本人只需完整讲清首个接受事件，不必手工复现程序全部内部传播。

## 4. 疲劳一致右移FCRS：S1到S2

从S1的DAG按反向拓扑顺序检查工序。右移不改变工件、机器、工人分配，也不改变三类资源顺序，只为目标工序增加最早释放时间。

```text
冻结CmaxStar = S1的全局Cmax
latestEnd = min(CmaxStar, 所有直接后继的开始时间)
proposalUpper = latestEnd - 当前实际AT
delta0 = proposalUpper - 当前开始时间
第a次尝试：delta_a = delta0 / 2^(a-1)，最多10次
release = 当前开始时间 + delta_a
→ 每次都完整重算恢复、疲劳、实际工时和三个目标
→ 开始时间必须严格推迟
→ 新Cmax不得超过冻结的CmaxStar
→ TEC和TWC均不得变差，且至少一个严格改善
→ 首个满足条件的回退尝试被接受
```

每次接受后立即更新当前调度，最终得到`S2`。

## 5. FM0辅助对照

在相同输入下关闭疲劳累积、恢复和工时反馈，可填写FM0辅助表。FM0只用于说明疲劳机制带来的差异，论文主讲解链仍是FM3的`S0→S1→S2`。

## 6. 当前生产目标口径

```text
机器空闲 = 机器非首次使用时 max(0, S - 机器上次结束时间)，首次为0
工序能耗 = actualAT * 机器功率 + 机器空闲 * 1.0
工序成本 = (actualAT + 机器空闲) * 工人成本率
Cmax = 所有工件第二阶段结束时间最大值
TEC = 全部工序能耗之和
TWC = 全部工序成本之和
```

这是当前规范生产评价器的明确口径。本人手算时不要擅自替换成其他论文版本公式；若认为口径不合理，在备注中单独提出。

## 7. 提交前检查

1. 每个工件的第二阶段开始不早于第一阶段结束；
2. 同一机器上的工序不重叠；
3. 同一工厂全局工人承担的工序不重叠；
4. 第一阶段资源与X0按工件身份一致；
5. 第二阶段资源符合动态选择规则；
6. S0、S1、S2每次移动后都重新传播疲劳和工时，不得只平移甘特条；
7. FCLS满足“真实提前、可行、Cmax不恶化”；FCRS满足“真实推迟、Cmax不超过CmaxStar、TEC/TWC不恶化且至少一项改善”；
8. FM0的疲劳全部为0；
9. FM3疲劳保持在`[0,1)`；
10. 所有本人结果保留至少12位小数。

完成后另存一份不可修改的提交副本，并计算SHA-256。提交前不要打开未来的程序答案目录。
