# I0本人手算协议

状态：`INPUT_ONLY`  
答案状态：`NOT_GENERATED`  
程序对照状态：`NOT_RUN`

## 目的

I0是一个5工件、2工厂、2阶段的小型说明性算例。它只用于：

1. 由学生本人完成FM3基础调度S0、FCLS后的S1和FCRS后的S2；
2. 手算完成并封存后，再与Java生产解码器比较；
3. 验算通过后，作为论文编解码、疲劳、粒子更新和局部搜索的统一说明性示例。

I0不用于算法性能结论。ESWA第四章10工件I1继续保留为工程黄金回归实例。

## 严格顺序

```text
读取输入和新版X0
→ 本人完成FM3基础调度S0
→ 本人计算FCLS候选并得到S1
→ 本人计算FCRS候选并得到S2
→ 本人填写目标与约束检查
→ 保存一份不可改的提交副本
→ 计算提交副本SHA-256
→ 才允许生成Java程序答案
→ 程序—本人结果逐字段比较
```

在本人手算提交前，禁止：

- 运行I0 Java解码器；
- 生成I0标准答案、甘特图或目标结果；
- 从I1结果推测I0结果；
- 用程序输出反填本人计算表。

## 编号规则

- 本人手算全部采用1基编号；
- `MA/WA`只直接编码第一阶段资源；
- 第二阶段机器、工人按输入文件中的规则动态选择；
- 工人使用“阶段局部编号”和“工厂全局编号”双标识。例如F1-S2局部W1对应F1全局W3；可用时间和疲劳状态按全局编号维护。
- `S0`是移位前完整FM3调度，`S1`是顺序应用全部被接受FCLS后的调度，`S2`是再顺序应用全部被接受FCRS后的最终调度；三者不得混写。

## 手算要求

- 允许使用普通计算器或由本人输入公式的Excel；
- 所有指数、对数中间值至少保留12位小数，最终展示可舍入；
- 计算母表保留全精度，不要只保留论文展示值；
- 发现不一致时先记录，不得直接修改为程序答案。
