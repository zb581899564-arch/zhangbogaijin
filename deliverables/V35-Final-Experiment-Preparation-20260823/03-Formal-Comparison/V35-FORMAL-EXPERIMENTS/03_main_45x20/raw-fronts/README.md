# Raw final fronts: currently empty by policy

Only a completed, individually registered physical run may create a child directory here. Required minimum files are `configuration.txt`, `status.properties`, `formal-gate.properties`, `provenance.properties`, `front.csv`, mechanism/audit outputs and `evidence-sha256.tsv`.

Do not place diagnostic, pilot, Shift-on, author-diagnostic, failed-preflight or synthetic fronts here. Do not construct `PFref` from a subset of this directory.
