# zhangbogaijin (张博改进)

分布式异构混合流水车间调度问题（DHHFSP）多目标优化算法深度改进与实验诊断框架。

## 目录概述

- `java-jmetal58/`：基于 jMetal 5.8 的算法主工程与核心实现（MOHPSO-QGS / A4-Pacing / BP-PDDR / 区域审计等）。
- `baseline-li-jmetal58/`：李明哲原论文算法 Java 基准工程对照。
- `docs/`：算法改进技术文档、路线图与全生命周期实验证据链（FC-5.2 / FC-6 / FC-6A / FC-6A.1 / FC-6A.2）。
- `PF对比发放_20_2_3_1/`：算例 `20_2_3_1` 下的 Pareto 前沿对比发放数据。
- `tools/` / `scripts/`：指标评测、自动化运行与数据分析工具集。
